   834→# **11) سير الاعتمادات Approval Workflows**
   835→
   836→اعتماد فاتورة مبيعات:\
   837→Draft Invoice → Review by Accountant → Approval by Chief Accountant →
   838→Post Invoice → Send to Customer → Register Payment → Reconcile Payment →
   839→Close Invoice\
   840→≤ 1,000: Accountant submit → Chief Accountant post\
   841→\> 1,000 و≤ 10,000: Accountant submit → Chief Accountant approve →
   842→Finance Manager post\
   843→\> 10,000: Accountant submit → Chief Accountant review → Finance Manager
   844→approve → General Manager approval → Posting\
   845→\
   846→اعتماد أمر شراء:\
   847→Purchase Request → Department Manager → RFQ → Supplier Comparison →
   848→Purchase Manager → Finance Budget Check → GM if high value → PO
   849→Confirmation\
   850→≤ 500: Department Manager\
   851→\> 500 و≤ 5,000: Department Manager + Purchase Manager\
   852→\> 5,000 و≤ 20,000: Department Manager + Purchase Manager + Finance
   853→Manager\
   854→\> 20,000: Department Manager + Purchase Manager + Finance Manager +
   855→General Manager\
   856→\
   857→اعتماد سند صرف:\
   858→Draft Payment Voucher → AP Accountant Review → Chief Accountant →
   859→Finance Manager → Cashier/Bank Officer Execution → Posting →
   860→Reconciliation\
   861→Cashier should not approve payment; AP Accountant should not execute
   862→bank transfer; approval and execution separated.\
   863→\
   864→اعتماد خصم مبيعات:\
   865→Quotation/SO → Sales Rep Discount → Check Limit → Sales Manager if
   866→exceeded → Finance if margin below threshold → Confirm SO\
   867→Sales Rep 5%, Sales Manager 15%, Finance if margin \<10%, GM if discount
   868→\>25%.\

   871→Inventory Count → Warehouse Keeper → Inventory Controller → Warehouse

  1085→# **17) قواعد الرقابة الداخلية Internal Controls**
  1086→
  1087→فصل المهام:\
  1088→- من ينشئ المورد لا يعتمد مدفوعاته.\
  1089→- من ينشئ الدفع لا يعتمد نفس الدفع.\
  1090→- أمين المخزن لا يغير تكلفة المنتج.\
  1091→- مندوب المبيعات لا يعتمد الخصومات العالية.\
  1092→- المحاسب لا يفتح الفترات المغلقة.\
  1093→- مسؤول النظام لا يرحل قيودًا محاسبية افتراضيًا.\
  1094→- أمين الصندوق لا يطابق البنوك منفردًا.\
  1095→- مسؤول المشتريات لا يعتمد بيانات المورد منفردًا.\
  1096→\
  1097→ضوابط مالية:\
  1098→- المستندات المرحلة لا تحذف.\
  1099→- القيود المرحلة تعكس فقط.\
  1100→- الإلغاء يجب أن يحتفظ بسبب.\
  1101→- كل مستند مرحل له Audit Trail.\
  1102→- الحركات بتاريخ سابق تحتاج صلاحية خاصة.\
  1103→- الفترات المقفلة لا تقبل ترحيلًا.\
  1104→- القيود اليدوية تحتاج اعتمادًا.\
  1105→- العمليات عالية القيمة تحتاج اعتمادًا متعدد المستويات.\
  1106→\
  1107→ضوابط المخزون:\
  1108→- المخزون السالب يحتاج اعتمادًا.\
  1109→- التسوية المخزنية تحتاج اعتمادًا.\
  1110→- تغيير تكلفة المنتج يحتاج موافقة مالية.\
  1111→- التحويل المخزني يجب اعتماده من المصدر والوجهة.\
  1112→- الهالك يحتاج سببًا.\
  1113→- المنتجات المتتبعة لا تتحرك دون Lot/Serial.\
  1114→- المنتجات المنتهية لا تباع إلا بتصريح.\
  1115→\
  1116→ضوابط المبيعات:\
  1117→- فحص حد الائتمان قبل تأكيد أمر البيع.\
  1118→- العميل المحظور لا يستقبل أوامر بيع جديدة.\
  1119→- الخصم العالي يحتاج اعتمادًا.\
  1120→- البيع تحت التكلفة يحتاج موافقة مالية.\
  1121→- لا تسليم قبل تأكيد أمر البيع.\
  1122→- لا ترحيل فاتورة إذا كان أمر البيع محظورًا.\
  1123→- المرتجع يجب أن يشير للفاتورة أو التسليم الأصلي.\
  1124→\
  1125→ضوابط المشتريات:\
  1126→- المورد يجب أن يكون معتمدًا قبل PO.\
  1127→- PO فوق الحد يحتاج اعتمادًا.\
  1128→- فاتورة المورد تطابق PO وGR.\
  1129→- فرق السعر/الكمية يحتاج مراجعة.\
  1130→- الدفع لا يتجاوز الفاتورة المعتمدة.\
  1131→- منع تكرار رقم فاتورة المورد.

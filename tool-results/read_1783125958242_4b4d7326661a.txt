    38→## 1. نظرة عامة على النظام
    39→
    40→### ما هو CoopStock Pro؟
    41→
    42→**CoopStock Pro** هو نظام تخطيط موارد مؤسسية (ERP) متكامل مصمم خصيصاً لتلبية احتياجات التعاونيات الزراعية والشركات الصغيرة والمتوسطة في المغرب. يجمع النظام بين إدارة المبيعات والمشتريات والمخزون والإنتاج والمحاسبة والموارد البشرية وعلاقات العملاء في منصة واحدة متكاملة.
    43→
    44→### الخصائص الرئيسية
    45→
    46→| الخاصية | الوصف |
    47→|---------|-------|
    48→| 🌐 **ثنائي اللغة** | دعم كامل للعربية (RTL) والإنجليزية (LTR) مع تبديل فوري |
    49→| 🌙 **الوضع الداكن** | ثلاثة أوضاع: فاتح / داكن / تلقائي (حسب النظام) |
    50→| 📱 **تصميم متجاوب** | يعمل على جميع أحجام الشاشات مع شريط جانبي قابل للطي |
    51→| 🧮 **محاسبة آلية** | قيود محاسبية تلقائية بالقيد المزدوج لكل عملية |
    52→| 🖨️ **طباعة احترافية** | مستندات مطبوعة بتنسيق احترافي مع ترويسة الشركة |
    53→| 📊 **تقارير ورسوم بيانية** | لوحات معلومات تفاعلية ورسوم بيانية متعددة |
    54→| 🔐 **صلاحيات دورية** | 8 أدوار مستخدمين مع مصفوفة صلاحيات تفصيلية |
    55→| 🔔 **نظام إشعارات** | إشعارات فورية مصنفة حسب النوع والأهمية |
    56→| 📤 **تصدير متعدد** | تصدير CSV / JSON / PDF لجميع البيانات |
    57→

   275→### أنماط التصميم المستخدمة
   276→
   277→| النمط | التطبيق |
   278→|-------|---------|
   279→| **SPA Routing** | تنقل من جانب العميل عبر Zustand بدون تحميل صفحات جديدة |
   280→| **Repository Pattern** | كل API route تتعامل مع نموذج واحد عبر Prisma |
   281→| **Singleton Pattern** | عميل Prisma كمثيل واحد مع تخزين مؤقت عالمي |
   282→| **Observer Pattern** | Zustand subscriptions لتحديث المكونات |
   283→| **Factory Pattern** | محرك المحاسبة ينشئ قيوداً محاسبية تلقائياً |
   284→| **Strategy Pattern** | نظام التصدير يدعم استراتيجيات متعددة (CSV/JSON/PDF) |
   285→| **Adapter Pattern** | طبقة i18n تحول النصوص حسب اللغة المختارة |

   293→#### 1. التخطيط المستقل للتمرير (Independent Scroll Layout)
   294→
   295→```
   296→┌──────────────────────────────────────────┐
   297→│ h-screen overflow-hidden (الجذر)          │
   298→│ ┌──────────┬────────────────────────────┐ │
   299→│ │ الشريط   │  الشريط العلوي (shrink-0)  │ │
   300→│ │ الجانبي  ├────────────────────────────┤ │
   301→│ │          │                            │ │
   302→│ │ overflow │  المحتوى الرئيسي            │ │
   303→│ │ -y-auto  │  overflow-y-auto           │ │
   304→│ │ overscroll│  overscroll-contain        │ │
   305→│ │ -contain │                            │ │
   306→│ │ min-h-0  │  min-h-0                   │ │
   307→│ │          │                            │ │
   308→│ │ [تمرير   │  [تمرير مستقل]             │ │

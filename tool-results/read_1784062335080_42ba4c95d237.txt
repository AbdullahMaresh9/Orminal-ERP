     1→# Alostaz Accounting ERP - Work Log
     2→
     3→This file tracks all agent work on the Alostaz-style accounting ERP system built with Next.js 16, Prisma, Tailwind 4, shadcn/ui.
     4→
     5→## Project Goal
     6→Build a comprehensive Arabic-first (RTL) accounting ERP inspired by الأستاذ (Alostaz) using the CoopStock Pro design architecture: SPA shell with sidebar nav, 24+ modules, automated double-entry accounting engine, bilingual (AR/EN), dark mode, professional printing & export.
     7→
     8→## Tech Stack (NON-NEGOTIABLE)
     9→- Next.js 16 App Router, TypeScript 5, Tailwind CSS 4, shadcn/ui (New York), Prisma + SQLite
    10→- Zustand (client state), TanStack Query (server state), React Hook Form + Zod, Recharts, Framer Motion
    11→- ONLY route visible to user: `/` (SPA via Zustand nav-store)
    12→- Backend logic via API routes at `/api/erp/*`
    13→
    14→## Architecture Decisions
    15→- Single SPA: `src/app/page.tsx` renders `<AppShell />` which switches modules via Zustand `nav-store.activeModule`
    16→- Arabic-first RTL default; `dir="rtl"` on `<html>`, toggleable to LTR via i18n-store
    17→- Each module = self-contained component in `src/components/modules/`
    18→- API routes follow REST: `/api/erp/{entity}` (GET/POST) and `/api/erp/{entity}/[id]` (GET/PUT/DELETE)
    19→- Accounting engine auto-generates balanced double-entry journals on sales/purchases/payments/production
    20→- System accounts (16) are seed-protected (isSystem: true)
    21→
    22→## Module Map (activeModule key → component)
    23→- dashboard, pos, sales-orders, sales-invoices, sales-credit-notes, sales-payments, clients
    24→- purchase-orders, purchase-invoices, purchase-credit-notes, purchase-payments, suppliers
    25→- products, categories, storehouses, inventory-incoming, inventory-outgoing, inventory-transfers, stock-takes, inventory-requisitions
    26→- chart-of-accounts, analytic-accounts, journal-entries, closed-periods
    27→- bank-accounts, safes, expenses, revenues, finance-transfers, finance-requisitions
    28→- reports, branches, partners, users, roles
    29→- settings, document-templates, audit-logs, notifications, profile

     5→     5→## Project Goal
     6→     6→Build a comprehensive Arabic-first (RTL) accounting ERP inspired by الأستاذ (Alostaz) using the CoopStock Pro design architecture: SPA shell with sidebar nav, 24+ modules, automated double-entry accounting engine, bilingual (AR/EN), dark mode, professional printing & export.

    14→    14→## Architecture Decisions
    15→    15→- Single SPA: `src/app/page.tsx` renders `<AppShell />` which switches modules via Zustand `nav-store.activeModule`
    16→    16→- Arabic-first RTL default; `dir="rtl"` on `<html>`, toggleable to LTR via i18n-store
    17→    17→- Each module = self-contained component in `src/components/modules/`
    18→    18→- API routes follow REST: `/api/erp/{entity}` (GET/POST) and `/api/erp/{entity}/[id]` (GET/PUT/DELETE)
    19→    19→- Accounting engine auto-generates balanced double-entry journals on sales/purchases/payments/production
    20→    20→- System accounts (16) are seed-protected (isSystem: true)
